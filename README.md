## プロジェクト構造（責務分離）

```
src/AINEPaint/
  App.xaml            アプリ起動・テーマ読み込み
  MainWindow.xaml     UIシェル（ツール / キャンバス / レイヤー / 下部バー）
  Themes/             テーマ定義（色は全てここに集約）
  Drawing/            キャンバス表示・ストローク描画
  Brushes/            ブラシ定義（ペン / 鉛筆 / 消しゴム）
  Layers/             レイヤーモデルと合成
  History/            Undo / Redo（操作履歴ベース）
  IO/                 PNG / JPG 読み書き、.ainpaint 形式
  Color/              色管理・カラーピッカー
  Settings/           設定の保存・読み込み
```

`Settings/` はまだ空。1機能ずつ埋めていく。

### 設計上の決めごと

- **キャンバスの画素は常に透明で始める。** 白背景は表示・書き出し時に敷くものとして扱う。
  焼き込むと消しゴムとPNG透明書き出しが両立しない。
- **ストロークは専用バッファに不透明で描き、指を離した時点で1回だけ合成する。**
  直接描くと、同じストローク内で線が重なった箇所だけ濃くなる。
- **Undo はタイル差分方式。** 変更されたタイルの変更前の中身だけを保存し、
  Undo / Redo は「入れ替え」という同一操作で処理する。
  レイヤーの追加・削除・並び替えは参照と並び順だけを保存するので画素の複製が起きない。
- **.ainpaint は ZIP + PNG。** 中身は project.json とレイヤーごとの PNG。
  独自バイナリにしないのは、圧縮と透明が両立し、万一のときZIPから絵を救出でき、
  項目を足しても古いファイルが読めなくならないため。
- **変形は確定するまで元のレイヤーを書き換えない。** 元の位置の穴は表示のたびに
  動的に開ける。これで Undo は確定時の1手で済み、キャンセルは捨てるだけで成立する。
  表示と確定に同じ処理を使うので、見た目と結果が必ず一致する。
- **レイヤー合成は PaintDocument.Render に集約。** 描画中のストロークは
  選択中レイヤーの中で SaveLayer によりグループ化してから合成する。
  これがないと、消しゴムが下のレイヤーや背景まで削ってしまう。
